# Hand Gesture Drawing

A real-time hand gesture recognition application that allows users to draw on the screen using hand movements detected by a webcam.

## Features

- Real-time hand tracking using a webcam
- Draw on the screen using your index finger
- Erase drawings using a two-finger gesture
- Smooth drawing experience
- Computer vision-based hand recognition

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## Installation

1. Install the required libraries:

```bash
pip install -r requirements.txt
```

## Usage

Run the application:

```bash
python draw_camera.py
```

Allow access to your webcam and use your hand gestures to draw on the screen.

## Requirements

- Python 3.12
- A working webcam
